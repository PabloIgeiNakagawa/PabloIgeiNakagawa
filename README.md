## Sobre mí

Soy Desarrollador Backend .NET Junior y estudiante avanzado de la Licenciatura en Sistemas (UNGS), a una materia de obtener la Tecnicatura Universitaria en Informática.

Actualmente trabajo en el desarrollo y mantenimiento de microservicios para el sector bancario, trabajando con C#, ASP.NET Core y SQL Server. Me especializo en la integración de servicios **REST (JSON)** y **SOAP (XML)**, lógica de negocio, manejo de datos transaccionales y buenas prácticas de arquitectura (SOLID / Clean Architecture).
